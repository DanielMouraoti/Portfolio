Projetos

  • Core API: microsserviços em Kubernetes no GCP

    API em Python com cache em Redis, fila no RabbitMQ e worker dedicado, evoluída de Docker Compose para Kubernetes. A VPC e o cluster GKE Autopilot são criados com Terraform, e o pipeline no GitHub Actions publica a imagem no Docker Hub com tag por commit.

    #kubernetes #terraform #gcp #github-actions #python #redis #rabbitmq

  • Lab de SRE e observabilidade

    Laboratório que junta monitoramento local e nuvem: Zabbix, Grafana e PostgreSQL em Docker Compose, e uma API FastAPI em uma instância EC2 provisionada com Terraform. A API tem rotas que simulam falha e estresse de CPU para testar alertas e dashboards.

    #sre #observabilidade #zabbix #grafana #terraform #aws

  • Patch management com Ansible

    Playbooks para padronizar o ciclo de atualizações de segurança em mais de 60 hosts Ubuntu, com execução centralizada via SSH.

    #ansible #automação #ubuntu
